# CopilotAdvisorSkill
Skill for Cowork
To install this in your cowork do either of the following
1. Open up Copilot Cowork and click on Customize on the left.
   Click on the "Add" button in the top right
   Click on the upload option.
   Drag the "SKILL.MD" file to the window

2. In your OneDrive go to the following folder -> Documents->Cowork->skills
   Create a folder called "cowork-advisor"
   upload the SKILL.md file to that folder.
